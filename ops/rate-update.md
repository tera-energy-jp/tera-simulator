# 単価マスタ更新ガイド

シミュレーターに埋め込まれている料金データを、**いつ・何を・どうやって**更新するかをまとめたものです。

前提として、このリポジトリには**自動更新の仕組みがありません**。
ここに書いた作業を人がやらないと、古い単価のまま公開され続けます。

対象ファイル：`index.html` / `cs-teiatsu.html` / `staff-*.html` / `school-simulator_*.html`

## まず読むべきこと：直近のタスク

**関西電力送配電・九州電力ほかが、2026年11月1日からの託送料金改定を申請済みです。**

単価は **2026年9月頃に公表される予定**です。
公表されたら、`"2026-11"` の期間を追加して全ファイルを再生成してください。
（この予定はHTMLのコメントにも書かれています）

## 更新カレンダー

### 毎月やること

**JEPXの実績を1ヶ月分追記する。**

年度の途中は「4月から最新確定月まで」の平均で年度の数字を出しています。
だから毎月追記しないと、**年度平均そのものがズレていきます**。ここが一番放置されやすいポイントです。

鮮度の確認方法は簡単で、**データの最新月が先月になっているか**を見るだけです。
たとえば2026年8月末の時点なら、2026年7月分まで入っていればOK。次に足すのが8月分です。

### 年に1回やること

| 時期 | 対象 | やること |
|---|---|---|
| 毎年2月頃 | 容量拠出金 | 翌年度の値を確認して追記。あわせて確定フラグ（`CAPACITY_CONFIRMED`）も`true`にする |
| 毎年5月 | 再エネ賦課金 | 新年度の単価を追加。5月検針分〜翌年4月検針分が、その年度の単価です |
| 年度改定時 | 送電ロス率 | 新年度の値を追記。各社の約款第32条が出典で、過去3年の実績平均で毎年見直されます |
| 年度改定時 | 託送料金 | 期間を追加して再生成（手順は下記）。臨時改定もあるので、申請情報にも注意 |

TERA手数料（5.1円/kWh）は固定運用なので、変更があったときだけです。

### 確定フラグを忘れるとどうなるか

容量拠出金と送電ロス率は、その年度の値が未確定だと**ひとつ前の年度の値をそのまま流用**する作りになっています。

つまり、**画面には数字が出るけれど正しくない**、という状態になります。
エラーにならないぶん気づきにくいので、値の追記と確定フラグの更新はセットでやってください。

## 更新の手順

データの本体（マスタ）は、このリポジトリではなく**生成元のプロジェクト側**にあります。

- マスタの正：`03_v10_source/tools/tso_history_data.py`
- 参考資料：`wheeling_tariff_history_memo.md` / `託送料金・送電ロス率_2022-2026_全数値表.md`

### 託送料金・送電ロス率を更新する

まず `tools/tso_history_data.py` の `PERIODS` に、適用開始年月をキーとして追加します。
そのうえで、各配列に値を1つずつ足してください。

そのあと、この2つを順番に実行します。

```bash
python3 tools/gen_tso_history.py      # HTMLに埋め込むブロックを生成
python3 tools/patch_cs_index_tso.py   # cs-teiatsu と index にパッチを当てる
```

繰り返しになりますが、`TSO_BY_FY` と `LOSS_BY_FY` のブロックは**このツールが生成するので、HTMLを直接書き換えないでください**。

### JEPXの実績を更新する

CSVから計算し直す流れです。

```
spot_summary_YYYY.csv  →  recompute_jepx.py  →  JEPX_MONTHLY / JEPX_MONTHLY_LC
```

30分コマ × 5種類のロードカーブごとに、月別の加重平均を出しています。**数値は税込前提**です。

なお計算時は、細かいデータから順に使われます。
月別ロードカーブ別 → 月別の単純平均 → 年度平均（`AREA_FY_AVG`）の順で、なければ次にフォールバックします。

### 生成したあと

再生成したHTMLをGitHubにアップロードすれば、1〜2分で公開ページに反映されます。
コミットメッセージに改定内容とバージョンを残しておいてください。

## まだ仮の値が入っているところ

以下は確定値ではありません。**お客様に提示する数字として使う前に、この表を確認してください。**

| 項目 | 状態 |
|---|---|
| 低圧区分の送電ロス率 | 仮の値。確定値への差し替えが必要です |
| 低圧の力率割引・容量拠出金の適用可否 | 仮設定。託送約款には低圧の力率割引の規定がないため、係数1.0で運用しています |
| 関西エリアの2023年度ロス率 | 出典そのものが怪しい状態。高圧3.1／特高1.3という値が前後の年度から1.0ポイントほど外れています。2023年度の実績で試算するときだけ影響するので、当面は出典の値のまま置いてあります。関西電力送配電の約款第32条で要確認 |

こうした未確定の項目は、画面に「仮・要確認」のバナーが出るようになっています。

## 覚えておくと迷わない仕様

**年度の区切りは「5月〜翌年4月」で統一**しています。
再エネ賦課金も容量拠出金も送電ロス率も、すべて同じ規則です。

**従量電灯の基本料金は2タイプ**あります。
北海道・東北・東京・中部・北陸・九州は単一型で「基本単価 × 契約kW」。
関西・中国・四国は2段型で「6kWまでは定額、超えたぶんは単価×超過kW」。計算は2段型が優先されます。

**再エネ賦課金・旧一電の料金表・燃料費調整は、すべて税込前提**です。データもそのまま入れています。

**この `ops/` フォルダもPagesで公開されます。** リポジトリ自体がパブリックなので実害はありませんが、機密情報は書かないでください。
