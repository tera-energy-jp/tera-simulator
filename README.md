# tera-simulator

テラエナジーでんきの**電気料金シミュレーター置き場**です。
ビルド済みの単一HTMLファイルをこのリポジトリに置き、**GitHub Pagesでそのまま公開**しています。
サーバーもビルド工程もなく、「HTMLを置く → 公開される」だけのシンプルな構成です。

- 公開URL：https://tera-energy-jp.github.io/tera-simulator/
- 公開の仕組み：GitHub Pages（`main`ブランチのルートを直接公開）

---

## 2. 更新の流れ

このリポジトリでは**ソースコードではなく生成済みHTMLだけ**を管理しています。
編集は別環境（ローカル等）で行い、完成したファイルをアップロードする運用です。

```
別環境でHTMLを修正・生成
        ↓
GitHubへアップロード（Web UIの「Add files via upload」または git push）
        ↓
GitHub Pagesに自動反映（通常1〜2分）
```

- バージョンは**コミットメッセージに記録**する慣習です（例：`R7: 追っかけシート Web直送 ＋ 登録パネルUI改訂（v39）`）
- staff系・school系のHTML内部にも `v36` `v37` のようなバージョン表記が埋まっています

## 3. さわる前に知っておくこと

**① 1.4MB級のHTMLを直接エディタで開いて編集しない**
staff系・school系は圧縮された単一ファイル（React + SheetJS内包）で、手編集はほぼ事故ります。修正は元の編集環境で行って、丸ごと差し替えてください。

**② ここに置いたファイルは全部インターネット公開される**
GitHub Pagesはルート直下を公開するので、社内向け（staff系）もURLを知っていれば誰でも開けます。検索避け（noindex）が入っているのは `taiken.html` だけ。**公開してはいけないデータや作業中ファイルは絶対に置かない**こと。

**③ 料金データ・単価はHTMLに埋め込み**
JEPX価格・燃料費調整・再エネ賦課金などのデータは外部APIではなくファイル内に直書きされています。つまり**単価改定のたびにHTMLの再生成・差し替えが必要**です。「サイトが古い単価のまま」はデータ更新漏れを疑ってください。

**④ staff系・school系はGoogle Apps Scriptに送信する**
「追っかけシート」への直送機能で `script.google.com/macros/s/...` のエンドポイントがHTMLに埋め込まれています。GAS側を再デプロイしてURLが変わった場合、**HTML側の差し替えもセットで必要**です。
